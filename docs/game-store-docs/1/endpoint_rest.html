Table of Contents

  • JSON (ejemplo de carro)

Endpoints

Método Ruta Descripción Body Respuesta OK Errores

POST

/api/carts

Crea un carro (token)

—

{ "token": "uuid" }

422

GET

/api/carts/{token}

Muestra carro + totales

—

{ token, status, items[], subtotal_cents }

404

DELETE

/api/carts/{token}

Vacía el carro (mantiene abierto)

—

{ "ok": true }

404

POST

/api/carts/{token}/items

Agrega ítem

{ "product_id": int, "quantity": int }

Carro serializado

400, 404, 409(stock), 422

PATCH

/api/carts/{token}/items/{id}

Actualiza cantidad

{ "quantity": int }

Carro serializado

400, 404, 409(stock), 422

DELETE

/api/carts/{token}/items/{id}

Elimina ítem

—

Carro serializado

404

POST

/api/carts/{token}/checkout

Cierra carro (descuenta stock)

—

{ "ok": true } + estado closed

404, 409(stock), 422
