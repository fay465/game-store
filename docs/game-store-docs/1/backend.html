Alternativas requeridas por pauta

Stack Descripción Pros Contras

Elixir + Phoenix (+ LiveView)

Actual (seleccionado)

Excelente concurrencia, latencia baja, LiveView simplifica frontend, productividad alta

Curva de aprendizaje, ecosistema menor que JS/Java

Kotlin + Ktor + HTMX

Alternativa Java VM

Tipado fuerte, ecosistema JVM, Ktor minimalista

Más boilerplate, real-time menos integrado

Swift + Vapor + React

Alternativa Apple/server-side Swift

Performance, tipado, integración Apple

Ecosistema server menor, React añade complejidad

Por qué Phoenix

  • Concurrencia (BEAM/OTP) → buen manejo de conexiones simultáneas.

  • Productividad: Generadores, Ecto, LiveView (menos JS).

  • Simplicidad para el alcance del ramo (un repositorio, monolito).
