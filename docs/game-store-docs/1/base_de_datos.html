Modelo (tablas relevantes)

Tabla Campos (tipo) Notas

products

id (PK), title (string), sku (string, único), price_cents (int), stock (int), image_url (string), inserted_at, updated_at

Catálogo simple; precios en centavos CLP.

carts

id (PK), token (uuid único), status (string: "open"/"closed"), inserted_at, updated_at

Un carro por token (cliente/visita).

cart_items

id (PK), cart_id (FK→carts), product_id (FK→products), quantity (int), inserted_at, updated_at

Ítems del carro con cantidad.

Diagrama (UML de tablas/relaciones)

Reglas

  • cart.status="closed" bloquea modificaciones posteriores.

  • quantity >= 1.

  • Validación de stock al agregar/actualizar (no sobrepasar products.stock).
