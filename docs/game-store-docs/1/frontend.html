Opciones

Opción Pros Contras Uso en este proyecto

Phoenix LiveView (seleccionada)

Build/CI/CD, más capas, más JS

Overkill para el alcance del ramo

Decisión

  • LiveView reduce tiempos de desarrollo, complejidad de estado y cumple con la pauta (API REST + frontend funcional).
