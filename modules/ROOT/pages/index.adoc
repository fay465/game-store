= Game Store – Proyecto Ecommerce (API REST + Frontend)
:page-aliases: home.adoc
:toc: macro
:toclevels: 2

Este proyecto implementa un **Ecommerce de venta de videojuegos** con:

* **Backend:** Elixir + Phoenix (API REST + LiveView para frontend)
* **Base de datos:** SQLite (según pauta de la asignatura)
* **Caso de uso foco:** Gestión de **Carro de Compra** (endpoint designado)

Requisitos de carga:

* **Presupuesto:** Medio
* **Cargas objetivo:** 10.000 transacciones/día (pico máx.: 100.000)
